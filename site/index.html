Nasıl çalışır

Dört adımda hatadan kanıtlanmış düzeltmeye.

Rewind arka planda kayıt yapar. Senin işin, hatanın başladığı anı bulup göstermek.

Geri sar

Panel açılır (Alt+Shift+R). Zaman çizelgesinde hatanın başladığı ana git.

Göster

Hatalı öğeye tıkla ya da öğesi olmayan hatalar için sayfa düzeyinde olay aç. "Ne olmalıydı?" sorusunu yanıtla.

Önizle, gönder

Ajana gidecek paketi gizlenmiş hâliyle gör. Paket MCP üzerinden ajanına iletilir.

Kanıtla

Ajan hatayı Playwright testiyle yeniden üretir, düzeltir, testi tekrar çalıştırır. Test geçince olay kapanır.

Olay paketi

Tek tıklama, tam bağlam.

Ajan tek bir paket alır. Paket, doğru dosyayı ve satırı ilk turda bulmak için gerekenleri içerir.

İşaretlenen öğe

CSS seçici, JSX'in yazıldığı dosya ve satır (source map ile), ±3 satır kod, bileşen yığını, props/state ve o andaki HTML.

Ağ

fetch/XHR istekleri, durum kodları, süreler, istek ve yanıt gövdeleri.

Konsol

Hatalar, uyarılar, yakalanmamış istisnalar, Promise redleri ve kaynak satırları.

Adımlar

Tıklamalar, girişler, tuşlar ve sayfa geçişleri. Ajan hatayı bunlarla yeniden üretir.

Store değişiklikleri

Zustand, Redux ya da kendi store'undaki değişiklikler, önceki → sonraki hâliyle.

Kanıt güveni

Kaynak çözüldü mü, öğe eşlendi mi, props/state canlı mı? Çözülemeyen satır uydurulmaz, açıkça işaretlenir.

Doğrulama

"Düzelmiş olmalı" yok. Kırmızı, sonra yeşil.

Ajanın run_repro aracı kayıttaki adımları gerçek bir tarayıcıda oynatır ve senin beklentini test olarak denetler. Olay yalnızca aynı testle önce kırmızı, ardından iki kez üst üste yeşil sonuç alınırsa "doğrulandı" diye kapanır.

kırmızıHata yeniden üretildi. Toplam 135030 ₺, beklenen 1380 ₺.
düzeltmeTek satır: discounted + Number(shipping)
yeşil ×2Olay kapandı: fixed

Koşul sağlanmazsa olay gerekçesiyle birlikte fixed_unverified olarak kapanır.

run_repro
{
  "id": "rw-20261026-150247-x6mn",
  "assertions": "await expect(target).toHaveText('1380 ₺');"
}

// Assertion metni hiçbir zaman çalıştırılmaz.
// Dar bir dilbilgisiyle ayrıştırılır; test kodu
// yalnızca bu ara temsilden üretilir.
// Olay verisi koda gömülmez; adımlar testin
// yanındaki .steps.json dosyasından okunur.
Güvenlik

Veri makinede kalır.

Kayıt ve olaylar yerelde tutulur. Şifre, token ve kişisel veriler ajana gitmeden, daha tarayıcıdayken gizlenir.

Yalnızca yerel

Alıcı yalnızca 127.0.0.1 üzerinde dinler. Olaylar proje kökündeki .rewind/ klasörüne yazılır ve git'e girmez.

Gönderimden önce gizleme

Anahtar adına ve desene göre: şifre, token, API anahtarı, JWT, çerez. Kart, IBAN ve T.C. Kimlik No sağlama algoritmasıyla doğrulanır.

Hata ayıklama değerleri korunur

Kupon kodu, tutar, tarih ve durum kodu olduğu gibi kalır. Doğruluk, 150'den fazla örnekli bir fixture setiyle CI'da denetlenir.

Sertleştirilmiş alıcı

Host doğrulaması (DNS rebinding), Origin izin listesi, zorunlu JSON ve gövde boyutu sınırı.

password=[REDACTED:password]  email=[REDACTED:email]  coupon=YAZ10  total=135030  Authorization: [REDACTED:token]

Gizleme bir güvenlik garantisi değildir. Ajana giden paket, ajanın kullandığı model sağlayıcısına gidebilir. Göndermeden önce önizlemeye bak.

Kurulum

İki paket, birkaç satır.

rewind-devtools uygulamana eklenen tarayıcı bileşeni, rewind-mcp ise ajanına bağlanan MCP sunucusu. Node.js 22 veya üstü gerekir.

1Paketleri kur

npx playwright install chromium

root.render(

    <Rewind />
  </>,

MCP araçları

Ajanın eline geçenler.

Ajan bu araçlarla olayı okur, hatayı yeniden üretir, gerekirse sana panelden soru sorar.

list_incidentsAçık, kapalı ya da tüm olayları listeler.
get_incidentRaporu Markdown olarak verir: köken, dosya:satır, kanıt güveni, beklenti, birincil kanıt, adımlar.
get_incident_eventsHam zaman çizelgesini JSON olarak verir.
get_dom_snapshotO andaki HTML'i verir; içinde arama yapılabilir.
run_reproAdımları gerçek tarayıcıda oynatır, beklentiyi işaretlenen anda denetler.
get_repro_scriptAynı testi çalıştırmadan üretir.
reply_to_incidentGeliştiriciye panelden soru sorar, istenirse yanıtı bekler.
mark_fixedOlayı kapatır. Doğrulama koşulunu sunucu denetler.
Bilinen sınırlar

Neyi yapmadığını da söyleyelim.

  • Yalnızca geliştirme ortamı içindir.
  • Bileşen bilgisi yalnızca React için çıkarılır.
  • Props/state değerleri işaretleme anında canlı uygulamadan okunur; rapor bunu belirtir.
  • Next.js ve React 18 kaynak çözümlemesi henüz gerçek kurulumlarda doğrulanmadı.
  • Canvas, video ve çapraz kökenli iframe içerikleri oynatılmaz; WebSocket mesajları kaydedilmez.
  • WSL2, Docker ve uzaktan geliştirme ortamları v1.0'da desteklenmez.
