# Ajan logoları

`site/index.html` içindeki "Ajanlar" bölümü bu klasördeki logoları kullanır. Dosya yoksa karo, ajanın baş harfleriyle görünür.

Logoları her ajanın kendi resmi basın/marka kitinden indirin ve kullanım koşullarına uyun. Kare, şeffaf arka planlı SVG (ya da PNG; o zaman `index.html`'deki uzantıyı değiştirin) önerilir.

| Dosya | Ajan |
|---|---|
| `claude-code.svg` | Claude Code (Anthropic) |
| `cursor.svg` | Cursor |
| `codex.svg` | Codex (OpenAI) |
| `github-copilot.svg` | GitHub Copilot |
| `gemini-cli.svg` | Gemini CLI (Google) |
| `windsurf.svg` | Windsurf |
| `cline.svg` | Cline |
